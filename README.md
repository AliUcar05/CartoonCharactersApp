# CartoonCharactersApp 🎬

CartoonCharactersApp is a desktop application developed in C# with Avalonia UI and .NET.

The application allows users to create and manage collections of cartoon characters, view character information, rate characters and manage their profiles.

It also includes authentication, administrator features, CSV import/export, statistics and MongoDB data storage.

## Main Features

- User registration and login
- Cartoon character collection management
- Add, edit and view characters
- Character rating system
- User profile management
- Administrator user management
- CSV import and export
- Statistics and charts
- MongoDB database integration
- MVVM architecture
